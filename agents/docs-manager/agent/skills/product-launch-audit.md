# Product Launch Audit Skill
This skill ensures a product is fully documented before it is marked as 'generally_available'.

## Checklist
1. [ ] Valid `product.yaml` exists in `products/`.
2. [ ] `product-overview.pdf` is generated and professionally formatted.
3. [ ] `getting-started.md` is present and accurate.
4. [ ] All features listed in YAML are explained in the `user-manual.md`.
5. [ ] `faq.md` addresses the top 3 most likely customer questions.
6. [ ] Release notes are drafted and approved.
7. [ ] The product appears correctly in the Portal API ` /products` list for entitled users.
