# Logging Utility Agent

A specialized Eve agent designed to provide structured logging capabilities to other agents or system processes.

## Purpose
This agent provides a standardized way to log system events, errors, and debug information using the `log` tool.

## Tools
- `log`: Logs a message with a specific level (INFO, WARN, ERROR, DEBUG) and optional context.

## Configuration
The agent is configured to use `openai/gpt-6.1-sol` via OpenRouter.
