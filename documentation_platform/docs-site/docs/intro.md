# Documentation Center

Browse the SnowStore product catalog and open a guide for any listed product. The sidebar also includes the longer product manuals.

## Software and downloads

| Product | What it does |
|---|---|
| [Local Launch — Local SEO Website Platform](./catalog-guides/local-seo-platform.md) | Build and export a local-service business website with editable pages, content SEO checks, a Business Profile checklist and manual keyword reports. Downloadable software; hosting is separate. |
| [BookScan Live](./catalog-guides/bookscan.md) | Scan or type an ISBN for a live lookup, estimated used-market value and a quick profit check. Built for book resellers. |
| [Page Builder](./catalog-guides/page-builder.md) | Build a products page in your browser without writing code, then export a single HTML file. Includes the Vanilla Webpage Template. |
| [Lead Generation Pipeline](./catalog-guides/lead-generator.md) | Turn a list of company names into websites, phone numbers and contact details. Python scripts you run on your own machine or on a schedule. |
| [Auto Blogger](./auto-blogger/product-overview.md) | Build weekly blog roundups from RSS feeds and web pages, then publish drafts to Hugo, WordPress or Ghost. No APIs or AI costs. |
| [Auto Scheduler](./auto-scheduler/product-overview.md) | A white-label weekly booking calendar for React with double-booking prevention and live stats. Built with TypeScript, Tailwind and shadcn/ui. |
| [Invoice & Biller](./catalog-guides/invoice-generator.md) | Make professional invoices in your browser and save them as PDFs. No account, no watermark, your data stays local. |
| [SaaS Financial Projection Engine](./catalog-guides/saas-financial-engine.md) | A 5-year SaaS financial model in one Excel workbook: MRR/ARR, unit economics, cohorts, headcount, cap table and scenarios. Works in Excel, Google Sheets and LibreOffice. |
| [GBP Analytics Dashboard](./catalog-guides/gbp-analytics-dashboard.md) | Turn Google Business Profile CSV reports into interactive charts: Search and Maps visibility, calls, website clicks and direction requests, compared across locations. Not affiliated with Google. |
