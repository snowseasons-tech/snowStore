Automate routine file tasks with Bash. Includes a free lesson and a four-session paid pack; Linux tested, with macOS and Windows WSL checks pending.

## Getting started

1. Open the README and run the first lesson in a practice directory.
2. Use the supplied sample files to try each command and inspect its output.
3. Keep a separate copy of any files you plan to rename, move or modify in your own workflow.
