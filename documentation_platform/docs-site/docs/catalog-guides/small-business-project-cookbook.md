Pilot edition with 12 project recipes, source, expected results, challenges and a master cheat sheet. Seller notes are not for student downloads.

## Getting started

1. Pick a project that matches a task you do, such as recording expenses or preparing a service quote.
2. Run the starter with the sample inputs and compare its output with the recipe.
3. Try the challenge on a separate copy before using your own records.
