title: "Page Builder"
---

Build a products page in your browser without writing code, then export a single HTML file. Includes the Vanilla Webpage Template.

## Getting started

1. Extract the download and open the builder in your browser.
2. Enter your page title and product details, then preview the layout.
3. Export the HTML file and open it in a browser to check links and mobile layout before publishing.
