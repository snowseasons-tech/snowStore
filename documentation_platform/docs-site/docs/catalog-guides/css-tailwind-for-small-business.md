Style service cards with plain CSS and Tailwind CSS v4. Includes a starter lesson and four paid sessions; Tailwind requires Node.js and a local build.

## Getting started

1. Read the README to identify the starter and its setup instructions.
2. Work through one styling exercise and preview it at desktop and mobile widths.
3. Compare the spacing, hierarchy and responsive behavior with the solution.
