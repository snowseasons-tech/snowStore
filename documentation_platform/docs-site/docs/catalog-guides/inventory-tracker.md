This product is retired. This guide is for customers who already have it.

A single-file inventory tracker for small sellers: stock levels, low-stock alerts and CSV import/export. Works offline, no account.

## Getting started

1. Open the saved tracker in your browser.
2. Test CSV import with a small sample and review the stock levels and low-stock alerts.
3. Export a backup before making bulk changes or switching browser profiles.
