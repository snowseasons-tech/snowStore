title: "BookScan Live"
---

Scan or type an ISBN for a live lookup, estimated used-market value and a quick profit check. Built for book resellers.

## Getting started

1. Open BookScan Live in your browser and enter a book’s ISBN.
2. Compare the result with the book in hand, including the edition and condition.
3. Use the estimated value and your acquisition cost to judge the margin. Check current listings before buying.
