Pilot edition with 12 creative beginner projects, commented source, sample data, instructions, outcomes, remix challenges and a master cheat sheet. No paid APIs or auto-publishing.

## Getting started

1. Unzip the cookbook and pick one of the 12 projects.
2. Read the project instructions, run the commented example against its sample data and compare the result with the expected outcome.
3. Save a copy and try the remix challenge before moving on.
