This product is retired. This guide is for customers who already have it.

A single-file operations dashboard with KPI cards, pipeline charts, an engagement wizard and CSV export. No backend needed.

## Getting started

1. Open the dashboard file from your existing download.
2. Review the sample KPI cards and charts, then try the engagement wizard.
3. Export a test CSV and check the columns before using it in reporting.
