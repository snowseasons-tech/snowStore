title: "Jekyll HTML and JavaScript Project"

A downloadable practice project combining Jekyll, HTML and JavaScript. Tailwind is optional and requires its documented local toolchain.

## Getting started

1. Read the package README and install the listed Jekyll dependencies.
2. Run the project locally and make a small HTML or JavaScript change.
3. Build the site and check the generated pages. Follow the package instructions if you choose to use Tailwind.
