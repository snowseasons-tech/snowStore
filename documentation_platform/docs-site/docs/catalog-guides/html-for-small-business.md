title: "HTML for Small Business"
---

Build a readable service page with HTML. Includes commented starter and solution files, exercises, answers and a cheat sheet; two lesson products are included, with six later lessons planned.

## Getting started

1. Open the lesson folder and read the exercise before opening the solution.
2. Edit the starter HTML to build the service page and refresh your browser to see the changes.
3. Check the page against the exercise answers and keep the cheat sheet handy.
