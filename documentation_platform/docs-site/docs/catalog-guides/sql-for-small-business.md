title: "SQL for Small Business"
---

Learn SQL with SQLite using fictional customers and jobs. Includes starter and solution files; two lesson products are included, with six later lessons planned.

## Getting started

1. Set up the practice database using the bundle README and sample data.
2. Start with read-only queries, then compare their results with the exercise answers.
3. Use the practice database for exercises that update or delete rows.
