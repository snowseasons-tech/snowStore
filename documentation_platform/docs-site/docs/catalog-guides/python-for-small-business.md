A beginner course with a free starter and four paid sessions, using Python standard-library projects. Cross-platform installation checks remain.

## Getting started

1. Choose the free starter or the paid pack and follow its README.
2. Run the first exercise with the provided data and compare the result with the expected output.
3. Change one input at a time to see how the script handles it.
