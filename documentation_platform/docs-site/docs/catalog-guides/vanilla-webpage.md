This product is retired. This guide is for customers who already have it.

A lightweight single-file products page with light/dark theme, responsive layout and no dependencies. Open it in a browser and it works.

## Getting started

1. Open the saved HTML file in a browser to inspect the original layout.
2. Edit a copy of the HTML to update its text and links.
3. Check the responsive layout and theme before publishing the edited file.
