Advanced tier for custom API integration development.

## Getting started

1. Identify the systems you want to connect and confirm what the advanced development tier covers in your quote.
2. Provide API documentation, a sample payload with sensitive fields removed and the expected data flow.
3. Test the agreed workflow in a sandbox and review error handling before enabling it in production.
