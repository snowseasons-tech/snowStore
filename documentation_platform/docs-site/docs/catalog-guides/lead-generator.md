title: "Lead Generation Pipeline"
---

Turn a list of company names into websites, phone numbers and contact details. Python scripts you run on your own machine or on a schedule.

## Getting started

1. Extract the download and follow its README to set up Python and the project dependencies.
2. Start with a small list of company names in the input format described in the package.
3. Review the resulting websites, phone numbers and contacts before importing them into another tool.
