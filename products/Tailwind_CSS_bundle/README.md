# CSS and Tailwind for Small Business
Snow Seasons Tech • Version 1.0

Style service cards first with plain CSS, then recreate them with Tailwind CSS v4 utilities. Basic HTML editing is recommended. This is a downloadable teaching project, not a hosted site.

Start with SETUP.md and free_starter/LESSON.md. The free CSS lesson opens directly in a browser and requires no build tools. The paid Tailwind pack requires a supported Node.js LTS installation and an internet connection for npm dependencies. Its generated stylesheet is not bundled; build it locally before judging the Tailwind examples. No browser CDN is used.

Includes commented starter and solution files, four paid sessions, exercises, answers, a combined cheat sheet, seller copy and an eight-lesson roadmap. Allow 45–60 minutes for the free lesson and 2–3 hours plus setup for the paid pack. Six later lessons are planned, not included.
