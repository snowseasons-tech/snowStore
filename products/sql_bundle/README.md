# SQL for Small Business
Snow Seasons Tech • Version 1.0

Learn SQL by storing fictional customers and jobs and building reports. Start with SETUP.md, then free_starter/LESSON.md and paid_pack/LESSON.md. No Python or Bash course prerequisite. Allow 45–60 minutes for the free starter and 2–3 hours for the paid pack, plus installation time.

Included: commented SQL starter and solution files, a command cheat sheet, exercises, answers and seller notes. The first two lesson products are included. Six additional course lessons are a roadmap only.

SQL is the language; SQLite is the database engine used here. SQLite shell dot commands are separate from SQL. Many SQL concepts carry over to PostgreSQL and MySQL, but installation, types and some syntax differ. Do not run the course scripts against a live business database.

Use a new database filename for each setup run. Setup scripts deliberately fail if their tables already exist; they do not delete or replace earlier work. All names and contact details are fictional. Job amounts are stored in whole cents, avoiding floating point dollar calculations. These are job values, not verified payments or revenue.

COMMAND_CHEAT_SHEET.md contains the complete quick reference. TESTING.md records verification and remaining platform checks. Markdown files open in a text editor or Markdown viewer.
