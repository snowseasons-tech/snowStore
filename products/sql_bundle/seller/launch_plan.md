# SQL for Small Business launch plan
Snow Seasons Tech

## Product structure
| Product | Proposed price | Delivery status |
| --- | --- | --- |
| Customer query starter | Free | Included for pilot review |
| Customer and job reporting pack | $15 | Included for pilot review |
| Eight lesson SQL course | $59 | Roadmap only |

These are proposed launch prices, not researched market benchmarks. The course targets owners with no coding experience and uses SQLite to avoid server administration in the first lessons.

## Course roadmap
1. Create a fictional customer list and filter results. Included.
2. Relate jobs to customers, build reports and practice rollback. Included in four sessions.
3. Clean missing values and normalize imported contact information.
4. Validate and import a CSV with a staging table.
5. Build date-based operational reports.
6. Introduce indexes and inspect query plans.
7. Back up, restore and verify a small database.
8. Capstone customer and jobs reporting workflow.

Lessons 3–8 are planned, not included. Backup commands in the cheat sheet are a reference, not a full additional lesson.

## Free listing copy
SQL Customer List Starter. Learn to create a practice customer table, display selected columns, filter by city and count records. Includes a written lesson, commented SQL files, practice answers and setup instructions. No coding experience required. Allow 45–60 minutes plus installation time. Uses SQLite on a computer; no paid account required.

## Paid listing copy
SQL Customer and Job Reports. Build a fictional customer-and-job database and learn filters, totals, grouping and joins. Practice changes inside a transaction that rolls back. Includes four guided sessions, heavily commented SQL scripts, exercises, answers and a SQL and SQLite command cheat sheet. Complete the free starter first. Allow 2–3 hours plus setup. Written lessons and downloadable files; video and personal coaching are not included. This project reports job values, not payment collection or accounting revenue.
