# dotTracker demo

Open [demo.html](demo.html) or [try it on the store](https://snowseasonstech.store/demos/inspections-intelligence.html).

Replay fictional asset positions, select a vehicle's trip, inspect moving/stopped/offline status, show a depot geofence's entry and exit events, and add a visual observation pin. The schematic uses invented coordinates, not real maps or GPS data. Offline assets show last-known positions and cannot receive a current-position observation.

This preview follows dotTracker's fleet and asset-tracking MVP scope. It has no telemetry, device ingestion, login, persistent storage, routing, or live alerts. `inspections-intelligence` is the store's existing product identifier for dotTracker.
