# Creator Code Cookbook
Snow Seasons Tech • Volume 1 • Version 2.0

Start with COOKBOOK.html for the styled, printable book or COOKBOOK.md for plain text. Twelve project folders have commented source, sample data, instructions, expected outcomes and remix challenges. MASTER_CHEAT_SHEET.md is the quick reference. TESTING.md separates completed checks from remaining browser and build checks.

This edition shifts the curriculum toward younger beginners, creative projects and social-media-related workflows. It replaces business quotes, invoices and inventory examples with creator profiles, captions, draft planning, post reports and a searchable content board. No social accounts, paid APIs or auto-publishing are needed.

Python 3.11+ recipes need no pip packages. Browser projects need no server except the recommended loopback origin for reliable checklist storage. Tailwind and Jekyll require their documented development toolchains and have not been compiled here. This is a review and pilot edition. The separate earlier language bundles are not modified by this cookbook revision.
