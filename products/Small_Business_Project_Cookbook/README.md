# Small Business Project Cookbook
Snow Seasons Tech • Volume 1

Start with COOKBOOK.html for the styled book, or COOKBOOK.md for plain text. Twelve recipes live in projects; each has its own README.md, source, expected results and challenges. MASTER_CHEAT_SHEET.md is the cross-language reference. TESTING.md lists completed checks and remaining release requirements. Seller notes are in seller and are not intended for student downloads.

Seven examples are new and five adapt earlier course projects. All required project sources are included. No paid packages are required to run the Python, Bash, SQLite or ordinary browser recipes; optional Tailwind and Jekyll require their documented development dependencies. This is a review and pilot edition, not a claim that all browser and build checks are complete.
