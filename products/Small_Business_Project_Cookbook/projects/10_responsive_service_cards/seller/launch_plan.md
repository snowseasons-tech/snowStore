# Styling course launch plan
Snow Seasons Tech

Roadmap: CSS selectors and spacing; Tailwind cards; flexbox and grid; accessible forms; responsive navigation; reusable themes; production build verification; capstone service page.

Free copy: Style Your First Business Service Cards. Learn selectors, spacing and responsive layout with a commented HTML/CSS starter, completed example and exercises. Allow 45–60 minutes; basic HTML recommended.

Paid copy: Tailwind Business Service Cards. Recreate a readable card layout using Tailwind v4 utilities, local builds, responsive variants and focus states. Includes four sessions, commented source, solutions, exercises and a cheat sheet. Allow 2–3 hours plus Node/npm setup. Generated Tailwind CSS must be built locally. No hosting, video or coaching included.

Before release: resolve dependencies, retain package-lock.json, compile both Tailwind examples, verify multiple browsers, keyboard use and phone widths, and pilot with beginners. Confirm support, license and refund terms. Keep seller notes private. See TESTING.md for actual verification limits.
