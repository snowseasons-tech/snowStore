# Python for Small Business
Snow Seasons Tech • Beginner course launch bundle • Version 1.1

Learn to code by building tools for everyday business tasks. Start with README.md in free_starter, then work through paid_pack. No previous coding experience is required. Allow 45–60 minutes for the starter and 2–3 hours for the paid pack, with breaks.

## What is included
- free_starter: setup instructions, a guided lesson, starter code, solution and practice.
- paid_pack: four guided sessions, calculator starter and solution, exercises and answers.
- seller: course roadmap, proposed prices, product copy and release checklist.

These lessons run locally using Python's standard library. There are no paid accounts or additional packages. The code is designed for Python 3.11 or later. Windows, macOS and Linux instructions are included; cross-platform installation checks remain part of the seller release checklist.

Use fictional business details while learning. The estimates omit taxes, payment collection and invoice numbering. Review calculations before adapting a learning project for actual business work.

Open the .md files in a text editor or Markdown viewer. Unzip before running the scripts. The remaining six course lessons are planned, not included.
