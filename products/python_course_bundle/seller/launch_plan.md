# Python for Small Business course plan
Snow Seasons Tech

## Audience and promise
For small-business owners who have never coded. Teach through estimates, expenses and follow-up tasks. Promise a concrete learning outcome rather than guaranteed savings or income.

## Product structure
| Product | Proposed price | Delivery status |
| --- | --- | --- |
| First calculator lesson | Free | Included |
| Service estimate lesson pack | $15 | Included for review and pilot testing |
| Eight lesson course | $59 | Roadmap only |

Prices are launch hypotheses, not market research. Do not sell the full course as a completed download until all lessons are built and reviewed. The paid pack extends the free lesson; the full course would include both.

## Eight lesson roadmap
1. First calculator: variables, arithmetic and running a script. Included as the free starter.
2. Service estimates: input, validation, discounts, functions and saving text. Included as the paid pack, spread across four sessions.
3. Customer follow-up checklist: lists, loops and fictional records.
4. Reusable invoice calculations: dictionaries, functions and clear rounding rules. No payment processing.
5. Persistent task tracker: JSON, reading files and recovery from invalid files.
6. Expense summaries: CSV input, missing values and category totals.
7. Organizing a business utility: modules, debugging and basic behavior checks.
8. Capstone follow-up tracker: combine skills, write instructions and demonstrate error handling.

## Proposed store copy
### Free product
Title: Build Your First Python Quote Calculator
Description: Start coding with a practical business example. Follow a written lesson to run a calculator, change its values and check its output. Includes starter code, a completed example, exercises and troubleshooting. No coding experience required. Allow 45–60 minutes. Downloadable ZIP; Python installation and a computer are required.

### Paid product
Title: Python Service Estimate Builder
Description: Turn a basic calculator into an interactive estimate tool. Learn to validate numbers, calculate discounts, organize code into functions and save an estimate as a text file. Includes four written sessions, starter and completed Python files, practice tasks and answers. Complete the free starter first. Allow 2–3 hours at your own pace. This is a learning project that calculates estimates before tax; it does not send invoices or collect payments.

Format: written Markdown lessons and downloadable Python files. Video and individual coaching are not included. Designed for Python 3.11 or later on Windows, macOS and Linux; confirm the tested platform list before publication.

## Suggested license to approve
A purchaser may study the lessons and modify the supplied code for their own business. Resale or redistribution of the lesson text and original course bundle is not included. This is a proposed policy for the seller to approve, not an existing customer agreement.

## Release checklist
- Test extraction, installation instructions and scripts on each operating system you advertise.
- Have at least three beginners complete the free lesson and paid pack; record where they need help.
- Verify normal, zero and 100-percent discounts, invalid numbers, cancellation and failed-save handling.
- Choose a support contact, response expectations and refund terms before listing. Do not imply live support unless provided.
- Package only free_starter for the free listing and only paid_pack plus shared setup instructions for the paid listing. Keep this seller folder private.
- Confirm the checkout price, download access and the exact files the buyer receives using a test purchase.
- Publish the free sample first; release the paid pack after pilot feedback. Build the remaining lessons in response to the questions students actually ask.
