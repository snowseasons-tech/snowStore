# Open and edit your course
Extract the ZIP first. Use a plain-text editor and a current browser. You do not need to install a framework, runtime or web server. The starter and solution filenames are different so you can compare them without overwriting the example.

Open free_starter/index_solution.html with your browser using Open File or your file manager. Open free_starter/index_starter.html in a text editor, edit, save, then open that file in your browser. Refresh after each saved change. Keep styles.css beside the HTML file.

Windows: ensure the filename ends in .html rather than .html.txt. Use plain-text mode, straight quotes and UTF-8. On macOS, disable rich-text formatting if using TextEdit. Linux users can use their preferred plain-text editor. No administrator permissions are required.

If you see source text rather than a webpage, check the extension and whether you opened the file in the editor or browser. If styling is missing, check that styles.css was extracted beside the HTML file. If changes do not appear, save, refresh, and confirm you opened the starter rather than solution.

Keep .js files beside each lesson's HTML and CSS. Classic scripts with defer are used so these examples can run directly from local files without a development server. Open the HTML page, not the .js file, in the browser. The browser's Developer Tools Console shows script errors. Never paste unknown commands into that console.

Official reference: https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting
