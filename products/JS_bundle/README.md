# JavaScript for Small Business
Snow Seasons Tech • Version 1.0

Add useful behavior to a small-business webpage. Build a click-to-show rate and then an interactive service quote calculator. A basic ability to edit HTML helps; the companion HTML course is recommended but all required markup is supplied.

Start with SETUP.md, free_starter/LESSON.md and paid_pack/LESSON.md. Allow 45–60 minutes for the starter and 2–3 hours for four paid sessions. Includes heavily commented HTML and JavaScript, starter and solution files, exercises, answers, a command and syntax cheat sheet, seller copy and roadmap. Six later lessons are planned, not included.

No server, packages, accounts or paid API is required. Open the extracted HTML files in your browser. The calculator accepts whole hours, whole dollar amounts and whole percent discounts. That teaching constraint simplifies arithmetic; fractional inputs are intentionally rejected. Nothing is saved, sent, billed or paid. Refreshing loses the displayed estimate.
