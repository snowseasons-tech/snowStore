# HTML for Small Business
Snow Seasons Tech • Version 1.0

Build a readable small-business service page with HTML. Start with SETUP.md, then free_starter/LESSON.md and paid_pack/LESSON.md. No previous coding experience is required. Allow 45–60 minutes for the free starter and 2–3 hours for the four paid sessions, plus breaks.

Includes commented starter and solution HTML, shared presentation CSS, exercises, answers, a tag and command cheat sheet, seller copy and a course roadmap. Two lesson products are included; six future lessons are planned. The CSS is supplied for readability; this is not a CSS course.

Everything runs locally. No form submission, analytics, hosting, payment processing or backend is included. Fictional .example email addresses cannot receive inquiries. Use fictional information while practicing. Browser keyboard navigation and accessibility review are part of the release checklist.
