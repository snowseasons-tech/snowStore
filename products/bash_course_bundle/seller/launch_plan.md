Prices are proposals to test, not market benchmarks.

## Eight lesson roadmap
1. Create a business workspace using variables and quoted paths. Included.
2. Generate sample records and create and restore a local archive. Included in four sessions.
3. Inspect files and produce a readable inventory report.
4. Select files by extension with loops and conditions.
5. Preview a file organization plan before making changes.
6. Record execution results and diagnose failures.
7. Run a reviewed task on a schedule, accounting for environment and paths.
8. Capstone reusable records workflow with documentation and restore checks.

Lessons 3–8 are not included. Do not list the complete course as an available finished download.

## Free product description
Build Your First Bash Business Workspace. Learn to run a script, customize a business name and create organized practice folders. Includes a written walkthrough, heavily commented starter and solution scripts, exercises and troubleshooting. No coding experience required. Allow 45–60 minutes plus setup. Requires a computer with Bash; Windows learners use WSL.

## Paid product description
Bash Business Records Archive Builder. Learn loops, reusable functions, file output, confirmation prompts and error handling while creating fictional business files and a compressed archive. Follow four written sessions and practice restoring your files. Includes commented starter and solution scripts, exercises and answers. Complete the free starter first. Allow 2–3 hours plus setup. Written lessons and scripts only; video and coaching are not included.

## Release checklist
- Pilot both products with three beginners and revise unclear steps.
- Verify Linux, macOS and WSL setup before advertising tested platform support. Current execution checks cover Linux only.
- Verify paths with spaces, existing parent folders, repeated runs, yes/no/EOF prompts, failed writes, failed archive commands and restoration.
- Approve support contact, response expectations, license and refund terms.
- Proposed license: learners may modify supplied scripts for their own business; redistribution of original course materials is excluded. Approve final wording before sale.
- Publish only free_starter and shared setup to the free listing; paid_pack and shared setup to the paid listing. Keep seller notes out of customer downloads.
- Test checkout and access before listing. Review all code examples with pilot learners.
