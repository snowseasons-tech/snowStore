# Bash for Small Business
Snow Seasons Tech • Version 1.0

Learn to automate routine file tasks with heavily commented Bash scripts. No prior coding experience is required. Start with SETUP.md, then free_starter/LESSON.md and paid_pack/LESSON.md. Open Markdown files in a plain-text editor or Markdown viewer.

Included: one free lesson, one paid pack with four sessions, starter and solution scripts, practice answers, seller copy and an eight-lesson roadmap. The remaining six lessons are planned, not included. Allow 45–60 minutes for the starter and 2–3 hours for the paid pack, plus setup time.

The scripts create new practice folders under your home directory. They do not move or delete your existing files. The archive is a local practice copy, not an off-device disaster recovery system. Use fictional data while learning.

Designed for Bash 3.2 or later with mkdir, mktemp and tar. Tested here on Linux; macOS and Windows WSL checks are still required before advertising verified support. No Python course prerequisite.
